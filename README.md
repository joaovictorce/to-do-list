# 📝 To Do List

Aplicação web desenvolvida para organizar e gerenciar tarefas de forma simples e prática.

## 🚀 Funcionalidades

- Adicionar novas tarefas
- Editar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Definir prioridade das tarefas
- Filtrar por todas, pendentes e concluídas
- Contador de tarefas
- Barra de progresso
- Limpar tarefas concluídas
- Armazenamento das tarefas com LocalStorage
- Layout responsivo para computadores e celulares

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📱 Responsividade

O projeto possui layout responsivo, adaptando-se a diferentes tamanhos de tela, incluindo dispositivos móveis.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar HTML, CSS e JavaScript, trabalhando conceitos como manipulação do DOM, eventos, armazenamento local e responsividade.,0
